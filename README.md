# 🍽️ NIMS – Restaurant Management System

A web-based restaurant management application developed using PHP and MySQL. The project helps manage restaurant operations, including user accounts, menu items, bookings, and orders.

## ✨ Features

- 🔐 User Registration and Login
- 🍔 Restaurant Menu Management
- 🛒 Shopping Cart and Order Management
- 📅 Table Booking System
- ⚙️ Admin Dashboard
- 📦 Order Status Management
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
